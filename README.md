# 📚 Estruturas de Dados em C

Este repositório foi desenvolvido como parte de uma **atividade prática acadêmica**, com o objetivo de consolidar os conhecimentos adquiridos sobre **Estruturas de Dados**, utilizando a linguagem **C**.

---

## 🎯 Objetivo

Aplicar na prática os principais conceitos de estruturas de dados, desenvolvendo soluções com base em:

- ✅ Listas (simplesmente e duplamente encadeadas)
- ✅ Pilhas (stacks)
- ✅ Filas (queues)
- ✅ Árvores binárias
- ✅ Ponteiros e alocação dinâmica de memória
- ✅ Operações de inserção, remoção, busca e percurso
- ✅ Manipulação de arquivos (se aplicável)

---

## 🛠️ Linguagem e Tecnologias

- 🔹 **C** – Linguagem de programação base para as implementações
- 🔹 **GCC / Clang** – Compiladores utilizados
- 🔹 **Visual Studio Code / Dev-C++** – Ambiente de desenvolvimento (opcional)
